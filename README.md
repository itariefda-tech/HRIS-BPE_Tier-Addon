# HRIS Security Outsourcing

## Ringkasan

HRIS ini dirancang khusus untuk **perusahaan outsourcing security/satpam**. Sistem ini bukan HRIS umum, tetapi sebuah **operating system** yang menggabungkan:

```text
HR + Operasional Lapangan + Command Center + Payroll + Billing
```

Dalam satu platform terintegrasi.

---

# 1. VISI PRODUK

Membangun sistem yang menjadi:

> **Operating System untuk perusahaan outsourcing security di Indonesia**

Sistem ini digunakan oleh:

* Guard / Satpam
* Supervisor Site
* Koordinator Area
* HR / Admin
* Payroll / Finance
* Management / Owner

---

# 2. MASALAH YANG DISELESAIKAN

HRIS biasa tidak cukup untuk industri security karena:

* multi-client & multi-site
* shift 24/7
* absensi berbasis lokasi
* patroli wajib
* incident reporting
* replacement mendadak
* payroll kompleks
* billing berbasis kontrak

Sistem ini dirancang untuk menyelesaikan semua itu dalam satu platform.

# 4. PRODUK EDITION (TIER SYSTEM)

Sistem ini dibagi menjadi 3 tier utama:

---

## 4.1 HRIS BASIC

### Tujuan

Digitalisasi dasar HR dan operasional.

### Isi utama

* Employee & Guard Master
* Client & Contract Basic
* Site & Post Management
* Deployment
* Schedule
* Attendance GPS basic
* Dashboard basic

### Cocok untuk

* perusahaan kecil–menengah
* baru migrasi dari Excel / WhatsApp

---

## 4.2 HRIS PRO

### Tujuan

Kontrol operasional lapangan yang lengkap.

### Tambahan dari Basic

* Patrol / Guard Tour
* Incident Management
* Leave & Replacement
* Approval Workflow
* Payroll Basic
* Reporting Pro
* Notification Basic

### Cocok untuk

* perusahaan outsourcing aktif multi-site
* butuh kontrol operasional real-time

---

## 4.3 HRIS ENTERPRISE

### Tujuan

Kontrol penuh operasional + keuangan + governance.

### Tambahan dari Pro

* Billing & Invoice
* Payment Tracking
* Advanced Approval Workflow
* Audit Log & Compliance
* Analytics Dashboard
* Multi-branch / Multi-company
* Client Portal
* API & Integration

### Cocok untuk

* perusahaan besar
* multi-klien & multi-area
* butuh kontrol manajemen
